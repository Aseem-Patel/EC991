Backward induction, one period at a time

The household now lives for $T$ periods and income $y_t$ can change with the date. The problem looks different at every date, because the horizon gets shorter, so the value function carries a date:

$$V_t(a) \;=\; \max_{a' \in \mathcal{A}} \; u\big(R a + y_t - a'\big) + \beta\, V_{t+1}(a'), \qquad t = T, T-1, \dots, 1,$$
$$V_{T+1}(a) = 0 .$$

The right-hand side is the same table as in VFI on a grid. One thing changes. In VFI the input row is a guess that we update until it stops changing. Here the input row is $V_{t+1}$, which we have already computed exactly. At $t = T$ it is the terminal condition, zero. So each table is filled in once, and after $T$ tables we are done. There is no convergence check.

The policy functions, one per date

Each table records, row by row, the column of its maximum. That gives a policy for every date, not one policy for all dates:

$$k^*_t(i) = \arg\max_{k} \; u\big(R a_i + y_t - a_k\big) + \beta\, V_{t+1}(a_k),$$
$$a'_t(a_i) = a_{k^*_t(i)}, \qquad c_t(a_i) = R a_i + y_t - a'_t(a_i).$$
  1. Store the index $k^*_t(i)$ for every state and date: an $n_a \times T$ matrix, pol[i, t].
  2. Turn indices into asset levels: apol = a[pol], again an $n_a \times T$ matrix.
  3. Consumption from the budget at each date: $c_t(a_i) = R a_i + y_t - a'_t(a_i)$. Income now depends on $t$.
  4. Simulate forward from a starting asset level: $i_{t+1} = k^*_t(i_t)$ for $t = 1, \dots, T$. Backward to solve, forward to simulate.

The same thing as code

The inner double loop is the one from the infinite-horizon solver. Only the outer loop changes: it runs over dates instead of iterations, and it stops after $T$ passes. This is solve_backward in src/backward.jl.

V = zeros(na, T + 1)                  # column T+1: terminal condition V_{T+1} = 0
pol = zeros(Int, na, T)
for t in T:-1:1                       # one table per date, from T back to 1
    for i in 1:na                     # one row of the table
        best, kbest = -Inf, 0
        for k in 1:na                 # one cell in that row
            c = R * a[i] + y[t] - a[k]
            c <= 0 && continue
            v = u(c) + beta * V[k, t + 1]   # the input row is V_{t+1}: known, not a guess
            v > best && (best, kbest = v, k)
        end
        V[i, t], pol[i, t] = best, kbest
    end
end
apol = a[pol]                         # a'_t(a_i)
cpol = [y[t] + R * a[i] - apol[i, t] for i in 1:na, t in 1:T]   # c_t(a_i)

Compare it with the infinite-horizon loop:

  • Input row. VFI uses a guess $V_\ell$ that is wrong until convergence. Backward induction uses $V_{t+1}$, which is exact.
  • Stopping rule. VFI stops when $\max_i |V_\ell - V_{\ell-1}|$ is small. Backward induction stops after $T$ passes.
  • Output. VFI returns one $V$ and one policy. Backward induction returns a matrix of each, one column per date.
  • The link. With constant income and $V_{T+1} = 0$, the column $V_t$ is exactly the VFI iterate $V_{T+1-t}$ started from a guess of zero. Backward induction is VFI from zero, stopped after $T$ steps and kept column by column.
